# ✈️ AirPassengers Time Series Forecasting

A Time Series Analysis project that predicts monthly airline passengers using **Linear Regression** with lag features.

## 🚀 Live Demo
https://air-passenger-forecast-project-1.onrender.com/

## 📊 Features
- EDA & Visualization
- Stationarity Check (ADF Test)
- Log Transformation & Differencing
- Lag Feature Engineering
- Linear Regression Model
- Streamlit Dashboard

## 🛠️ Tech Stack
Python • Pandas • NumPy • Scikit-learn • Statsmodels • Streamlit

## ▶️ Run

```bash
git clone https://github.com/AkashAnuragi/AirPassengers-TSA.git
cd AirPassengers-TSA
pip install -r requirements.txt
python train.py
streamlit run app.py
```
